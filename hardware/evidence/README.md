# Captura de evidências físicas

Uma pasta por peça deve ser criada aqui antes de promover uma medição no registro:

```text
hardware/evidence/
  U1/
  RFID1/
  SEN1/
  SEN1_PROBE/
  TK1/
  LID1/
  HW1/
  HARNESS/
```

Para cada `MEAS-*` do registro, salvar:

1. `MEAS-XXX-photo-top.jpg` e `MEAS-XXX-photo-bottom.jpg`, com régua ou escala no mesmo plano;
2. `MEAS-XXX-readings.md`, contendo três leituras, instrumento, resolução, lote/revisão e data;
3. `MEAS-XXX-review.md`, com a revisão independente e a decisão `APPROVED_BY_MEASUREMENT` ou `REJECTED`.

Use milímetros. Fotos do viewer, imagens de anúncios e dimensões copiadas de outro lote são referências, não evidência de fabricação.
